Proyecto universitario · En equipo

DOA

Plataforma web educativa para mejorar la comunicación entre docentes y alumnado.

  • HTML5
  • CSS3
  • JavaScript
  • PHP
  • MariaDB
  • SQL
  • GitHub
  • Trello

DOA (Docentes y Alumnos) fue mi primer proyecto en equipo dentro del grado. Desarrollamos una propuesta para centros educativos con acceso por roles, gestión de asignaturas y tareas, entregas del alumnado y una página de presentación y compra para GTI.

Participé en las distintas fases: entrevista con el cliente, brainstorming, reuniones documentadas, análisis de usuarios, historias de usuario, arquitectura de información, wireframes, prototipos HiFi e implementación.

Lideré los dos últimos sprints.

Proceso y participación

Partimos de una entrevista que simulaba las dificultades de recoger y entender las necesidades de un cliente real. Después realizamos sesiones de brainstorming y reuniones de equipo documentadas con actas.

Trabajamos la arquitectura de la información, las historias de usuario, los wireframes y los prototipos de baja y alta fidelidad antes de implementar el código.

En la documentación del proyecto preparé las disecciones de la pantalla de Login, la simulación de TPV y la página de asignatura del alumno.

Decisión técnica: estructura modular

Planteamos la aplicación por módulos de funcionalidades, organizados en directorios. El objetivo era poder añadir o retirar funcionalidades reduciendo el impacto en el resto del proyecto.

La implementación utilizó HTML5, CSS3, JavaScript y PHP, con MariaDB y SQL para la base de datos. También utilizamos GitHub y Trello para organizar el trabajo.

Proyecto personal · Aplicación móvil

Lazo

Una aplicación privada para compartir momentos y señales con mi pareja.

  • Flutter
  • Dart
  • Firebase
  • Riverpod

Desarrollé Lazo como una aplicación para mi pareja y para mí. Ya tenía experiencia con Flutter y Dart por mi formación en el ciclo. En este proyecto aprendí a integrar Firebase y sus servicios.

La aplicación utiliza autenticación, base de datos y almacenamiento en Firebase.

Funcionalidades y servicios

El proyecto incluye Firebase Authentication, Cloud Firestore y Firebase Storage. También incorpora notificaciones mediante Firebase Cloud Messaging y notificaciones locales.

La gestión del estado se apoya en Riverpod. El proyecto incluye selección y compresión de imágenes, recursos propios y localización.

Cómo aprendí la tecnología

Aprendí a utilizar estas herramientas buscando información y apoyándome en IA mientras construía la aplicación. Después revisé cómo encajaba cada implementación con la estructura y las necesidades del proyecto.
